# NodeRed (archived)

This repo is archived and no longer maintained. It used an old infinimesh API.

To use Node-RED with infinimesh, use the MQTT bridge or webhook addon from [infinimesh/addons](https://github.com/infinimesh/addons). The [Node-RED guide](https://github.com/infinimesh/docs/blob/main/guides/node-red.md) shows both.
